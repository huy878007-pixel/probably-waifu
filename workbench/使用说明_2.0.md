# 深空娘化 · 立绘工作台 2.0

双击本目录的 `index.html` 打开。已打开旧页面时刷新即可；继续使用原来的浏览器和原来的文件路径，才能读到原有本地标注。无需安装、联网或启动服务。

## 先看清场景，再配图

左边选角色，中间选择剧情场景，右边选立绘。统计区分手工标注、默认配图和缺图，默认配图不等于人工检查完成。

每个场景显示阶段、游戏事件编号、原版服装和可查证的触发条件。并列分组可能是互斥路径、成交回调、被捕或离场回调，**不能按上下排列理解成必定连续发生**。其他人和玩家说的话只显示上下文，不能给他们套当前角色的图。

两组混合结局已经拆开：

- 塞尔皮科：黑市离站、革命军、治安部重返制服三条路线；领取奖励和告别虽然复用同一个台词编号，依然可以分别配图。
- 埃莉诺：母亲获释后的拾荒生活、母亲遇害后的革命军两条路线；共用道谢和告别分别保留各自服装。

同一台词出现在多场景时，卡片标记“复用”。重新配图只修改当前场景。旧版全局手工标注继续生效，详情会提示“沿用旧版全局标注”；程序不会猜测用户原本想用在哪条路线，也不会擅自清空它。

右侧“发布版 · 语义复核”是当前默认素材，共156张，包含新补的贝利、亚瑟等差分。旧基础图和剧情图仍保留，避免破坏已有标注的图片编号。缩略图去掉透明边距便于观察，发布包原图不受影响。

## 操作

- 单句或框选一段台词，然后单击右侧立绘；Shift 可在同分组内扩展选择。
- 点“选择本分支”只选该组本人台词，再选图。
- 拖图到单句、入场或退场槽位；拖到事件标题栏将套用该场全部本人台词。
- 双击右侧立绘也会套用当前场景全部本人台词，操作前看清场景。右键提供本场/本角色批量操作；已移除会导致跨角色串图的“全部角色”操作。
- 入退场槽位可添加、删除变体；单击条件名称改名。名称必须唯一，避免导出覆盖。
- **变体名称只是标注信息，写一个条件名字不会自动给游戏新增判断代码。**
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` / `Ctrl+Y` 重做。历史最多80步，重新打开页面后历史不保留，标注保留。
- `Delete` 清除选择。共享台词只在当前场景回默认图，其他场景不变。
- `Esc` 取消选择；键盘聚焦台词后 Enter/空格选择，聚焦右侧图片后 Enter/空格配图。
- `Ctrl+F` 聚焦当前角色台词搜索；支持中文、英文、台词钩子、事件编号、阶段和条件。
- 阶段筛选、“含默认图的场景”、“含未标注的场景”、“与复核图不同”可组合使用。结果保留完整场景上下文。切换筛选会取消原选区，避免误改隐藏台词。
- 选中详情显示完整台词、钩子、阶段、服装、条件和当前图。手工图与复核图不同时给出默认图对照；不同不自动判为错误。

## 保存、备份、导入

仍使用原浏览器存储键 `dsh-portrait-map-v1`。读取页面时不改写存储。首次编辑前保留本次打开时的原始存储到 `dsh-portrait-map-v1-backup`，之后延迟200ms自动保存。顶部显示读取、保存中、已保存或保存失败。切到后台、关闭页面时会尝试补存。

保存失败时先点“备份手工标注”下载JSON。这个文件仅包含实际手工内容，不把默认图伪装成手工结果。换电脑、浏览器、清缓存或搬文件夹前也请备份。

“导入”支持完整配图方案及手工备份。先完整校验角色、台词、图片归属、场景和变体，再显示数量确认；按名称合并，未涉及的现有标注保留，文件中同名项覆盖。导入前保存 `dsh-portrait-map-v1-before-import`，导入后可撤销。文件不合法时整批不导入。

“还原备份”恢复自动保留的打开前存储，覆盖前另存 `dsh-portrait-map-v1-before-restore`。这是覆盖操作，界面会确认。

## 导出格式

“导出配图方案”和“只导出当前角色”导出工作台方案JSON。2.0使用 **version 3**：

- `characters[角色].contexts[场景ID][台词key]`：手工场景覆盖；null表示当前场景回默认图，不继承旧全局值。
- `characters[角色].scenes`：源游戏事件、sprite、阶段、条件及各场景最终配图。
- `characters[角色].lines`：兼容旧全局方案。**只读此字段会丢失结局差异。**

例如 `serpicoConclusion::rev` 是编辑器场景ID，真实游戏事件仍是 `serpicoConclusion`，服装是 `serpico_rev`。

**工作台方案不是游戏的 StoryMap.json，不能重命名覆盖运行时文件。** 下游打包器必须读取scenes/contexts，并转换成Mod支持的钩子。当前Mod的spriteLines/keyContext也不是编辑器场景格式。误导入运行时JSON会被拒绝。本次未改动已安装游戏或发布DLL。

对应游戏Build 26317870：17角色、98场景、698条可配图的场景台词、671个不同本人台词key。重复台词按实际出现的场景分别展示。

在工作台目录执行：

```text
node tools/upgrade-data.js
pwsh -NoProfile -File tools/release-thumbs.ps1
node tools/check.js
node tools/scenes-check.js
node tools/uitest.js
node tools/scenes-uitest.js
```

upgrade-app.py是一次性界面升级记录，不需再次运行。浏览器测试使用系统Chrome及临时隔离配置，不使用作者实际浏览器配置。
