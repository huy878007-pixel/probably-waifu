## 三、之前判错的地方（已修，不用改图）

| 现象 | 真实原因 | 现在 |
|---|---|---|
| 一批卡显示成「电话」，但游戏里没有电话剧情 | 我解析漏了两种写法：`new StoreClient { identifier = "x", spriteName = "y" }` 对象初始化器、`CreateLouTalkClient("louBoxDrop")` 工厂方法 | 已补上，多出 4 个真实事件（`louBoxDrop` / `louBoxCollect` / `louDemandCollect` 等），卡数 87 → 91 |
| 剩下 7 张没有立绘 | 真的是没有客户端立绘的剧情对话（导师到访/教程、王尔德的规矩、卢的后续留言、埃莉诺被捕段） | 标成「无固定立绘」或「沿用前一阶段」 |
| 塞尔皮科「制服阶段」错用「三路线结局」那套 | 那套里有一格叫"重回制服"，关键词撞了 | 只用「制服阶段」 |
| 卢的留言卡用了「执法者伪装」 | 沿用了前一张卡（伪装）的阶段 | 现在用普通装 |
| 埃莉诺「拾荒阶段」没有对应切片 | 素材里确实没做拾荒六格 | 改用同阶段的**基础立绘**（第四阶段_拾荒者） |
