## 入场闪回的原因与修复

旧请求使用 `femaleUpper_0`，它是精灵资源名而不是当前原生字典编号。原生字典缺失时随机回退到其他客人。实际后台复现记录中，引导与采购入场分别读到了 `scavFemale_8`、`scavFemale_5`，随后才被换成小小。

核心库的通用 VisitorApi 增加可选 `portrait` 入场资源。原生第一次查询精灵时便返回内容包指定的图片，避免展示随机客人。小小指定平静入场图；到店后的表情仍按原有台词和交易判定切换。

核心只负责通用接口，人物名称、素材、概率、需求、售货清单均保留在美化包。新包应与核心 1.6.12 配套使用。

## 接口补充

`VisitorApi.CreateCustomer` 新增可选 JSON 字段：

- `portrait`：当前 `pack` 内的入场图片路径。`sprite` 需提供一个有效原生编号作为禁用或资源失败时的回退。
- `intent`：`buy`（默认）、`sell`、`sellbuy`。
- `offers`：最多 6 个当前游戏中存在的物品 ID；允许重复以表示多件。只有 `sell` / `sellbuy` 可提供，需包含介绍对话。工厂构造阶段不发货，当前客人的介绍结束后只摆放一次。
